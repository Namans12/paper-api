# Acceptance examples

For the worked examples, bin 4 was Ready when the sheet was printed. An explicit mark of the original value can be a fresh observation. If the desk now disagrees, ask the reviewer. This covers a case a basic three-way comparison can miss.

| Paper mark | Desk value at review | Expected outcome |
|---|---|---|
| Blank | Unavailable | Preserve Unavailable. Record no observation. |
| Needs inspection | Ready | Propose Needs inspection. Persist it on confirmation. |
| Unavailable | Unavailable | Record agreement without rewriting the bin. |
| Needs inspection | Unavailable | Show a conflict and the crop. A reviewer can keep Unavailable, accept Needs inspection, or defer. |
| Ready explicitly checked | Unavailable | Show a conflict. The volunteer observed Ready after the sheet was issued. |
| Double-marked or unreadable row | Any | Require correction from the crop or deferral. Preserve the desk value until an explicit resolution. |
| Valid mark, then another desk edit while review is open | New revision | Reject the stale confirmation atomically, show the new desk value, and allow review again. |
| Same sheet photographed twice or confirmed concurrently | Any | One receipt and at most one application. Retrying returns that receipt. |
| Different issued sheet with identical rows | Any | Review it as a separate observation using its own saved baseline. |

Blank row: no box marked; the volunteer made no observation. Explicit mark: exactly one box clearly marked; a fresh observation even when it equals the printed value. Deferred row: the reviewer chose a physical recheck; the desk value is preserved and the deferral is recorded on the receipt.
